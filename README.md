# Date and Leap Year Checker (C++)
<br>
A beginner-friendly C++ program that checks whether a given date is valid.
<br>

# Features 
Validates date, month, and year.
<br>
Identifies leap years using leap year conditions.
<br>
Calculates the number of days in a given month.
<br>
Determines whether the month falls in the first or second half of the year.
<br>

# Concepts Used
Conditional Statements (if-else)
switch Statement
Logical Operators
Leap Year Logic
User Input and Output
<br>

# Language
C++
